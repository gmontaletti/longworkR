# Set Vecshift as Default ggplot2 Theme

Sets the vecshift theme as the default for all ggplot2 plots in the
current session.

## Usage

``` r
set_vecshift_theme(...)
```

## Arguments

- ...:

  Arguments passed to theme_vecshift()

## Examples

``` r
if (FALSE) { # \dontrun{
# Set vecshift theme as default
set_vecshift_theme()

# Set with custom options
set_vecshift_theme(base_size = 14, grid = "none")
} # }
```
