# Add Hierarchical Metrics to Graph

Internal helper to add hierarchy-specific metrics to tidygraph object.

## Usage

``` r
.add_hierarchical_metrics(tg, hierarchy_type, root_nodes)
```

## Arguments

- tg:

  tidygraph object

- hierarchy_type:

  Type of hierarchy

- root_nodes:

  Specified root nodes

## Value

Modified tidygraph object with hierarchy info
