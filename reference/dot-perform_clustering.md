# Perform Clustering with Specified Method (Internal)

Perform Clustering with Specified Method (Internal)

## Usage

``` r
.perform_clustering(features_matrix, n_clusters, method, nstart, seed)
```

## Arguments

- features_matrix:

  Numeric matrix

- n_clusters:

  Number of clusters

- method:

  Clustering method

- nstart:

  Number of random starts

- seed:

  Random seed

## Value

Clustering result object
