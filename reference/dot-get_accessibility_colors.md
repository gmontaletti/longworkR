# Get Accessibility-Friendly Color Palettes

Internal helper to generate colorblind-friendly and accessible color
palettes.

## Usage

``` r
.get_accessibility_colors(palette_name, use_bw, accessibility_mode, n = NULL)
```

## Arguments

- palette_name:

  Name of color palette

- use_bw:

  Use black and white version

- accessibility_mode:

  Enable high contrast mode

## Value

Character vector of colors
