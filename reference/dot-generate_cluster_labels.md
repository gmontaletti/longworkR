# Generate Bilingual Cluster Labels Based on Characteristics (Internal)

Generate Bilingual Cluster Labels Based on Characteristics (Internal)

## Usage

``` r
.generate_cluster_labels(cluster_profiles, verbose = FALSE)
```

## Arguments

- cluster_profiles:

  data.table with cluster means

- verbose:

  Logical

## Value

data.table with cluster_id, cluster_label_en, cluster_label_it
