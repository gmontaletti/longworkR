# Stratified Sampling to Preserve Variance Structure (Internal)

Stratified Sampling to Preserve Variance Structure (Internal)

## Usage

``` r
.stratified_sample(features_matrix, sample_size, seed = 123)
```

## Arguments

- features_matrix:

  Numeric feature matrix

- sample_size:

  Integer. Target sample size

- seed:

  Random seed

## Value

Integer vector of sample indices
