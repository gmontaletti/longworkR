# Add Network Nodes with Styling

Internal helper to add styled nodes to ggraph plots.

## Usage

``` r
.add_nodes(size_var, size_range, color_var, alpha, colors)
```

## Arguments

- size_var:

  Variable for node sizing

- size_range:

  Range for node sizes

- color_var:

  Variable for node coloring

- alpha:

  Node transparency

- colors:

  Color palette

## Value

ggraph node layer
