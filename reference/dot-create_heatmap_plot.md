# Create Heatmap for Cluster Profiles (Internal)

Create Heatmap for Cluster Profiles (Internal)

## Usage

``` r
.create_heatmap_plot(profiles_norm, metrics, color_palette, title, theme_base)
```

## Arguments

- profiles_norm:

  data.table with normalized profiles

- metrics:

  Character vector of metric names

- color_palette:

  Color palette

- title:

  Plot title

- theme_base:

  Base theme

## Value

ggplot object
