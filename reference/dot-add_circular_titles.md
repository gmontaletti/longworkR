# Add Circular Plot Titles

Internal helper to add titles for circular plots.

## Usage

``` r
.add_circular_titles(tg, title, subtitle, circular_type, node_order)
```

## Arguments

- tg:

  tidygraph object

- title:

  Custom title

- subtitle:

  Custom subtitle

- circular_type:

  Type of circular layout

- node_order:

  Node ordering method

## Value

ggplot2 labs layer
