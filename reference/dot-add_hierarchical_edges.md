# Add Hierarchical Edges

Internal helper to add styled edges for hierarchical plots.

## Usage

``` r
.add_hierarchical_edges(
  width_var,
  width_range,
  show_labels,
  colors,
  accessibility_mode
)
```

## Arguments

- width_var:

  Edge width variable

- width_range:

  Edge width range

- show_labels:

  Show edge labels

- colors:

  Color palette

- accessibility_mode:

  High contrast mode

## Value

ggraph edge layer
