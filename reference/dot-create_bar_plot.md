# Create Grouped Bar Chart for Cluster Profiles (Internal)

Create Grouped Bar Chart for Cluster Profiles (Internal)

## Usage

``` r
.create_bar_plot(profiles, metrics, color_palette, title, theme_base)
```

## Arguments

- profiles:

  data.table with cluster profiles

- metrics:

  Character vector of metric names

- color_palette:

  Color palette

- title:

  Plot title

- theme_base:

  Base theme

## Value

ggplot object
