# Add Network Metrics to tidygraph Object

Internal helper to calculate and add network centrality metrics.

## Usage

``` r
.add_network_metrics(tg, size_var, color_var)
```

## Arguments

- tg:

  tidygraph object

- size_var:

  Variable for node sizing

- color_var:

  Variable for node coloring

## Value

Modified tidygraph object with metrics
