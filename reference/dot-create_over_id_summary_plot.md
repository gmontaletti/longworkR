# Create over_id Summary Plot

Internal helper to create summary visualization of over_id distribution.

## Usage

``` r
.create_over_id_summary_plot(data, colors, accessibility_mode, facet_by)
```

## Arguments

- data:

  Filtered pipeline data

- colors:

  Color palette

- accessibility_mode:

  High contrast mode

- facet_by:

  Faceting variable

## Value

ggplot2 object
