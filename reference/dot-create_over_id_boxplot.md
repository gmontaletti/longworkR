# Create over_id Boxplot

Internal helper for boxplot visualization.

## Usage

``` r
.create_over_id_boxplot(data, colors, accessibility_mode, facet_by)
```

## Arguments

- data:

  Filtered pipeline data

- colors:

  Color palette

- accessibility_mode:

  High contrast mode

- facet_by:

  Faceting variable

## Value

ggplot2 object
