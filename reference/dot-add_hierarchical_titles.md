# Add Hierarchical Plot Titles

Internal helper to add titles for hierarchical plots.

## Usage

``` r
.add_hierarchical_titles(tg, title, subtitle, hierarchy_type, direction)
```

## Arguments

- tg:

  tidygraph object

- title:

  Custom title

- subtitle:

  Custom subtitle

- hierarchy_type:

  Type of hierarchy

- direction:

  Layout direction

## Value

ggplot2 labs layer
