# Add Network Labels

Internal helper to add node labels to ggraph plots.

## Usage

``` r
.add_labels(show_labels, label_size, label_repel, accessibility_mode)
```

## Arguments

- show_labels:

  Show labels flag

- label_size:

  Size of labels

- label_repel:

  Use repelling labels

- accessibility_mode:

  High contrast mode

## Value

ggraph label layer or NULL
