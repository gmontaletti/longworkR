# Add Network Titles and Subtitles

Internal helper to add informative titles to network plots.

## Usage

``` r
.add_network_titles(tg, title, subtitle, layout, size_var)
```

## Arguments

- tg:

  tidygraph object

- title:

  Custom title

- subtitle:

  Custom subtitle

- layout:

  Layout algorithm used

- size_var:

  Node sizing variable

## Value

ggplot2 labs layer
